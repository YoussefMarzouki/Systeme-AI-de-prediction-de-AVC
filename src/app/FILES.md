# Angular App Files

Main Angular application package.

## Files

- `app.component.ts` - Root Angular component class.
- `app.component.html` - Root component template.
- `app.component.css` - Root component styles.
- `app.component.spec.ts` - Unit test scaffold for the root component.
- `app.config.ts` - Angular app providers and configuration.
- `app.routes.ts` - Role-based routes for agent, general doctor, and specialist pages.

## Folders

- `components/` - Reusable layout/navigation components.
- `models/` - TypeScript interfaces/types for API data.
- `pages/` - Routed screen components.
- `services/` - Angular API and state services.
