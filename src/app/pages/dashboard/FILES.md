# Dashboard Page Files

Patient dashboard and history panel.

## Files

- `dashboard.component.ts` - Loads evaluated dossiers, filters records, opens history, and navigates to reports/intake/MRI upload.
- `dashboard.component.html` - Dashboard table, risk stats, action buttons, and history drawer UI.
- `dashboard.component.css` - Dashboard, table, status badges, and history drawer styles.
- `dashboard.component.spec.ts` - Unit test scaffold for the dashboard component.
