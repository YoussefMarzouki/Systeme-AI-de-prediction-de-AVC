# Rapport Page Files

Report display/export page.

## Files

- `rapport.component.ts` - Receives report data through navigation state, normalizes it, saves/restores session state, and prints reports.
- `rapport.component.html` - Report template showing risk, MRI analysis, clinical analysis, specialist review, and disclaimer.
- `rapport.component.css` - Report page layout, cards, badges, and print-related styles.
- `rapport.component.spec.ts` - Unit test scaffold for the report component.
