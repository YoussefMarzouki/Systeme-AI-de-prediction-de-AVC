# Validation Queue Page Files

Specialist report queue.

## Files

- `validation-queue.component.ts` - Loads pending/validated/rejected reports and handles queue tab changes.
- `validation-queue.component.html` - Specialist queue table/cards and navigation to case evaluation.
- `validation-queue.component.css` - Queue layout, tabs, badges, and card styles.
- `validation-queue.component.spec.ts` - Unit test scaffold for the validation queue component.
