# Case Evaluation Page Files

Specialist report-review screen.

## Files

- `case-evaluation.component.ts` - Loads case detail, edits specialist assessment fields, and validates/rejects reports.
- `case-evaluation.component.html` - Case detail, MRI preview, AI scores, notes, and validation controls.
- `case-evaluation.component.css` - Specialist review page styles.
- `case-evaluation.component.spec.ts` - Unit test scaffold for the case evaluation component.
