# Model Files

TypeScript interfaces and types for frontend data.

## Files

- `utilisateur.model.ts` - User, doctor, agent, and admin frontend types.
- `patient.model.ts` - Patient data shape.
- `dossier-patient.model.ts` - Patient dossier data shape.
- `analyses.model.ts` - AI analysis and risk-evaluation data shapes.
- `rapport.model.ts` - General report data shape.
- `rapport-validation.model.ts` - Validation queue, case detail, validate/reject payload, and comment types.
