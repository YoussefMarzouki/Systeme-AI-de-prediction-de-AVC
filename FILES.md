# Frontend Files

Angular frontend for StrokeAI.

## Files

- `angular.json` - Angular workspace/build configuration.
- `Dockerfile` - Builds the frontend container.
- `default.conf` - Nginx configuration used in the frontend container.
- `package.json` - NPM scripts and dependencies.
- `package-lock.json` - Locked dependency versions.
- `postcss.config.js` - PostCSS configuration.
- `proxy.conf.json` - Development proxy that sends `/api` calls to the backend.
- `tailwind.config.js` - Tailwind CSS configuration.
- `tsconfig.json` - Main TypeScript configuration.
- `tsconfig.app.json` - TypeScript configuration for the Angular app.
- `tsconfig.spec.json` - TypeScript configuration for Angular tests.
- `build_log.txt` - Saved build output/log information.
- `build_output.txt` - Saved build output information.
- `README.md` - Angular-generated project README.

## Folders

- `src/` - Angular source code.
- `public/` - Static public assets.
