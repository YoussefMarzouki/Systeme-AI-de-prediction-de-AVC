# Repository Files

Repositories isolate direct database operations from controllers and services.

## Files

- `__init__.py` - Exports repository classes.
- `patient_repository.py` - Database operations for patients.
- `dossier_repository.py` - Database operations for patient dossiers.
- `donnees_cliniques_repository.py` - Database operations for clinical/symptom entries.
- `image_irm_repository.py` - Database operations for MRI image records.
- `rapport_repository.py` - Database operations for reports and report status queries.
